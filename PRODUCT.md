# Product

## Register

brand

## Users

Plugin developers, open-source contributors, paying customers (Voxy is a premium Minecraft plugin), and the broader developer community discovering Mevera Studios' portfolio. They land here to find documentation, browse projects, evaluate libraries, and understand what the studio builds.

## Product Purpose

Documentation hub for Mevera Studios' open-source libraries — Imperat, Lotus, Scofi, Synapse, Voxy. The site exists to showcase each project's capabilities, guide developers through getting started, and establish Mevera Studios as a maker of well-crafted developer tools. Success looks like a visitor arriving, quickly finding what they need, and leaving with confidence in the library and the studio behind it.

## Brand Personality

Bold, crafted, unconventional. A studio identity that refuses to blend into the SaaS/corporate-docs template. Confident but not loud, detailed but not busy. The brand carries a precision-engineering ethos: every pixel, transition, and word earns its place.

## Anti-references

Generic SaaS / corporate documentation sites. Avoid Stripe-clone or Vercel-clone aesthetics: muted blue nav bars, rounded-corner-everything, soft shadows, anonymous templates. The site should not look like it was generated from a startup boilerplate.

## Design Principles

1. **Studio identity first** — The site feels like a studio's craft, not a generated template. Every detail reflects Mevera's personality, not the default docs-site pattern.
2. **Precision over decoration** — Effects (WebGL rays, 3D cards, electric borders) earn their place through purpose, not novelty. No gradient text, no glassmorphism as default, no decorative flourishes that don't serve the content.
3. **Meet every visitor where they are** — Plugin devs hunting for API refs, customers evaluating Voxy, casual browsers exploring the portfolio. Each path is clear and frictionless.
4. **AAA accessibility as baseline** — Not aspirational. Contrast ratios, focus management, keyboard navigation, reduced motion preferences — ship it right from the start.
5. **Show, don't tell** — The libraries are about craft; the site demonstrates that same craft through its own execution. Clean code, precise spacing, intentional motion.

## Accessibility & Inclusion

WCAG AAA preferred. All body text at 7:1 contrast minimum; large text at 4.5:1. Full keyboard navigation, visible focus indicators, reduced-motion alternatives for every animation. The dark theme is the default; light theme is a precise toggle, not an afterthought.
