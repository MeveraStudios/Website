# Supported Plugins

These plugins build on the [Voxy API](/docs/Voxy/v1/developer-api/Getting-Started) to read data, react to events, or extend Voxy's features. If you maintain a plugin that integrates with Voxy, it can be listed here.

## Plugins

| Plugin | Description | Voxy APIs used | Links |
|--------|-------------|----------------|-------|
| Arcade Minigames | Arcade-style minigames plugin | Party | [SpigotMC](https://www.spigotmc.org/resources/arcade-minigames.49093/) |
| Arcade Minigames 2 | Next-generation arcade minigames plugin | Party | [SpigotMC](https://www.spigotmc.org/resources/arcade-minigames-2.125889/) |
| TheLab Minigame | Multi-game "The Lab" minigame plugin | Party | [SpigotMC](https://www.spigotmc.org/resources/thelab-minigame-the-rework-is-here.26665/) |
| ClashWars (BedWars) | BedWars-style team minigame | Party | [SpigotMC](https://www.spigotmc.org/resources/bedwars-clashwars-minigame.51340/) |
| Cops and Crims | Cops and Crims gun-game minigame | Party | [SpigotMC](https://www.spigotmc.org/resources/cops-and-crims-minigame-major-rework-is-here.16641/) |

:::note{label="Using the Party API"}
Each of these plugins integrates with Voxy through the [Party API](/docs/Voxy/v1/developer-api/Guilds-and-Parties) to move players together across games.
:::

## Get your plugin listed

Building something on top of Voxy? To have it featured here, share:

- **Name** and a one-line description of what it does.
- Which **Voxy APIs** it uses (Player Data, Economy, Ranks, Moderation, Events, and so on).
- A **link** where users can download or view it (SpigotMC, Modrinth, GitHub, etc.).

See the [Developer API](/docs/Voxy/v1/developer-api/Getting-Started) section for how to depend on Voxy and start integrating.
