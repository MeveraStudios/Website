# Introduction
Lotus is a modern gui library for paper/spigot, designed to be ensure smooth development experience when creating guis using paper/spigot.

## Basic Definitions
Before we start, let's define some basic terms that we will be using throughout the documentation.
- **Menu**: A menu is a template for creating custom gui that can be opened for a player.
- **MenuView**: Represents an opened menu session for a player.
- **Button**: A button is an interactive element that can be added to a menu, it can be clicked by the player to perform an action.
- **Pagination**: A feature that allows you to split the content of a menu into multiple pages, and navigate between them.


## Integrating Lotus
To use lotus, you need to initialize a `Lotus` instance in your `onEnable` method.
Here is a simple example:
```java
public class Test extends JavaPlugin {

   private Lotus lotus;
	
   @Override
   public void onEnable() {
     lotus = Lotus.builder(this)
							 .build();
   }

}
```

### Creating your first menu
To create a menu, you need to extend the `Menu` class and implement its methods:
```java
public class TutorialMenu implements Menu {

    @Override 
    public @NotNull MenuTitle getTitle(DataRegistry extraData, Player opener) {
        return null;
    }

    @Override 
    public @NotNull Capacity getCapacity(DataRegistry extraData, Player opener) {
        return null;
    }

    @Override 
    public @NotNull Content getContent(DataRegistry extraData, Player opener, Capacity capacity) {
        return null;
    }
}
```

Now lets break down the methods we need to implement:
- `getTitle`: This method is responsible for providing the title of the menu.
- `getCapacity`: This method is responsible for providing the capacity of the menu, which determines the size of the menu (number of slots).
- `getContent`: This method is responsible for providing the content of the menu, which includes the buttons and their positions/slots.

In the next sections, we will go through each of these methods in detail and see how to implement them to create a functional menu.
