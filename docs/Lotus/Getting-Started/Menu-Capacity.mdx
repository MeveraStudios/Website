# Menu Capacity
In Lotus, the capacity of a menu defines how many rows and columns it has, which in turn determines how many buttons can be placed in the menu and how they are arranged.
The capacity is defined through the `getCapacity` method of the `Menu` interface.

## Constructing a Capacity
To create a capacity, use the methods provided by `Capacity` class.
You need to either dictate the number of rows for the gui, or dictate the number of slots directly.

### Example of creating a capacity with rows:
```java
    @Override
    public @NotNull Capacity getCapacity(DataRegistry extraData, Player opener) {
        return Capacity.ofRows(3);
    }
```

### Example of creating a capacity with slots:
```java
    @Override
    public @NotNull Capacity getCapacity(DataRegistry extraData, Player opener) {
        return Capacity.ofSlots(27); // 27 slots is equivalent to 3 rows in a standard Minecraft inventory menu
    }
```

## Dynamic Capacity
Just like menu titles, the capacity of a menu can also be dynamic and can change based on various factors such as the player opening the menu, or any extra data you want to provide.
Moreover, you can also dictate the capacity to be based on the number of buttons you have in the content, so that the menu will automatically adjust its capacity to fit all the buttons without having empty slots as much as possible.
this is called a `flexible capacity`.

### Example of flexible capacity.
```java
    @Override
    public @NotNull Capacity getCapacity(DataRegistry extraData, Player opener) {
        int numberOfButtons = ...;
        return Capacity.flexible(numberOfButtons)
    }
```

Moreover, you can even set a maximum limit for the expansion of the flexible capacity, so that if the number of buttons exceeded that limit, the capacity will not expand anymore and it will just be fixed to that maximum limit.
```java
    @Override
    public @NotNull Capacity getCapacity(DataRegistry extraData, Player opener) {
        int numberOfButtons = ...;
        return Capacity.flexible(numberOfButtons, 27); // the maximum limit for expansion is 27 slots.
    }
```

:::tip
You need to know how many buttons you're going to have in your content before you can decide the capacity of your menu, 
especially if you're going to use a flexible capacity, since the number of buttons is what determines the expansion of the flexible capacity.
:::
