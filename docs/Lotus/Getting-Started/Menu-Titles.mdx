# Menu Titles
In Lotus, the title of a menu is not just a static string; it can be dynamic and can change based on various factors such as the player opening the menu, or any extra data you want to provide.
 This is achieved through the `MenuTitles` methods.

## Constructing a MenuTitle
Lotus allows you to create legacy titles or modern titles.
The difference is that, Legacy titles are based on the traditional chat color codes, while modern titles are based on the Adventure text components, which provide more flexibility and features for creating rich and interactive titles,
depending on the Minecraft version and the platform you are targeting, you can choose the appropriate type of title for your menus.

`MenuTitles#createLegacyTitle(String)` is used to create a legacy title from a string that may contain color codes.
```java
MenuTitles.createLegacyTitle("&aHello, &bWorld!");
```

`MenuTitles#createModern` has 3 variants:

One that accepts a `Component`:
```java
Component yourAdventureComponent = Component.text("Hello, World!").color(NamedTextColor.GREEN);
MenuTitles.createModern(yourAdventureComponent);
```

One that accepts a `String`,
which will be parsed as a **mini-message** string, allowing you to use **mini-message** formatting in your titles:
```java
MenuTitles.createModern("Hello, <green>World</green>!");
```

and even if you want to use your own `MiniMessage` instance with custom tags and settings, you can use the variant that accepts a `MiniMessage` instance along with the string to parse:
```java
MiniMessage miniMessage = yourCustomMiniMessageInstance();
MenuTitles.createModern(miniMessage, "Hello, <green>World</green>!");
```

## Static vs Dynamic Titles
A static title is a fixed string that does not change, while a dynamic title can be generated based on the context of the menu opening.
For example, you might want to include the player's name in the menu title, or display different titles based on the player's permissions or the state of the game.

### Dynamic Title Example
Here's an example of how to implement a dynamic menu title:

```java
    @Override
    public @NotNull MenuTitle getTitle(DataRegistry extraData, Player opener) {
        return MenuTitles.createModern("<blue><bold> Welcome " + opener.getName());
    }
```
In this example, the title of the menu will greet the player by name, creating a personalized experience for each player who opens the menu.
