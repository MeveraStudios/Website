# What is Lotus?

**Lotus** is a modern, type-safe **GUI framework for Paper/Spigot** servers. It lets you design chest-style inventories declaratively — you describe *what* a menu should look like, and Lotus handles the rest: rendering, click routing, repainting, pagination, and per-player state.

## Why Lotus?

Writing GUIs directly against the Bukkit `Inventory` API gets painful fast — raw slot math, listener boilerplate, mutable state scattered across your plugin, and no safety net when you forget to cancel a click.

Lotus replaces all of that with a small, sealed vocabulary:

- **`Menu`** — an immutable template (title, capacity, content) resolved per player.
- **`MenuView`** — the live session for one viewer, carrying its own state.
- **`Button`** — a sealed set of six variants covering everything from plain icons to multi-state cycles.
- **`Content`** / **`ContentBuilder`** — a fluent DSL for placing buttons using slots, ranges, masks, and directional lines.
- **`DataRegistry`** — typed per-view state to replace `Map<String, Object>`.
- **`Pagination`** — immutable definition paired with a per-player session.

:::tip
If you've used frameworks like React or Jetpack Compose, the mental model will feel familiar — you describe the UI as a function of state, and the framework repaints when state changes.
:::

## One-minute tour

Here's a fully working three-row chest menu with a bordered frame and a clickable diamond in the center:

```java
Lotus lotus = Lotus.builder(this).debug(true).build();

public final class ShopMenu implements Menu {
    @Override public @NotNull Capacity capacity(MenuView<?> view) {
        return Capacity.ofRows(3);
    }

    @Override public @NotNull Component title(MenuView<?> view) {
        return Component.text("Shop");
    }

    @Override public @NotNull Content content(MenuView<?> view) {
        return Content.builder(capacity(view))
            .fillBorder(Button.of(new ItemStack(Material.BLACK_STAINED_GLASS_PANE)))
            .set(1, 4, Button.clickable(
                new ItemStack(Material.DIAMOND),
                (v, e) -> v.viewer().sendMessage("Bought!")))
            .build();
    }
}

lotus.openMenu(player, new ShopMenu());
```

That's the whole menu. No listeners, no slot arithmetic, no mutable global state.
